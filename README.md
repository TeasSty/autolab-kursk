# АвтоЛаб — сайт сервиса BMW (Курск)

Одностраничный лендинг автотехцентра **АвтоЛаб** (Гремяченская, 5).

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

Деплой на GitHub Pages:

```bash
npm run deploy
```

## Эффекты и производительность

- «Ворота бокса» на hero, amber-sweep, Bay Switcher, parallax, canvas-лучи фар
- Автоотключение тяжёлого FX при `prefers-reduced-motion`, Save-Data или слабом устройстве (≤4 CPU / ≤4 GB)
